# Regalo para Mamita Lore

Proyecto listo para subir a GitHub y desplegar en Vercel.

## Cómo usar

```bash
npm install
npm run dev
```

## Desplegar en Vercel

1. Sube esta carpeta a GitHub.
2. Entra a Vercel y elige **New Project**.
3. Importa el repositorio.
4. Framework: **Vite**.
5. Build Command: `npm run build`.
6. Output Directory: `dist`.

## Música

El proyecto ya incluye música ligera en:

`public/music/mama.mp3`

Para usar tu canción exacta, reemplaza ese archivo por tu MP3 y conserva el mismo nombre: `mama.mp3`.

## Fotos

Las fotos están configuradas con los enlaces que enviaste. Si quieres cambiarlas, edita `src/main.tsx` en las constantes `images` y `gallery`.
